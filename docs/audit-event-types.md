# Типы объектов и действий журнала

Документ фиксирует пользовательские подписи фильтров журнала. Имена таблиц,
классов и значения `AuditAction` в базе данных не переименовываются.

## Типы объектов

| Тип в данных | Подпись в интерфейсе | Когда возникает | Решение |
| --- | --- | --- | --- |
| `organization` | Организация | Создание, изменение или удаление организации-заказчика | Оставлен: самостоятельная бизнес-сущность |
| `contract` | Договор | Создание, изменение и смена статуса договора | Оставлен: основной документ системы |
| `additional_agreement` | Доп. соглашение | Регистрация, активация и смена статуса д.с. | Оставлен: самостоятельная редакция договора |
| `application` | Заявка | Регистрация, изменение и смена статуса заявки | Оставлен: самостоятельный документ |
| `order`, `order_item`, `annual_demand`, `specialty` | Строка заказа | Изменение редакции заказа, специальности или потребности по году | Переименован из «Заказ»: сотрудник работает с конкретной строкой специальности; внутренние типы БД не меняются |
| `document`, `document_attachment`, `excel_import` | Файл | Загрузка, удаление, восстановление файла или импорт Excel | Оставлен: объединяет пользовательские файловые операции |
| `faculty`, `contract_faculty`, `application_faculty` | Факультет | Изменение справочника или привязки факультета к документу | Оставлен: показывает изменения факультетского состава |
| `app_user` | Пользователь | Создание учётки, изменение ФИО/роли или смена пароля | Оставлен: нужен для управления доступом |
| `app_setting` | Системная настройка | Изменение рабочей настройки, например фиксации входов | Оставлен: системные изменения должны быть видны |

## Действия

| Действие | Подпись в интерфейсе | Когда возникает | Решение |
| --- | --- | --- | --- |
| `CREATE` | Создано | Создана организация, документ, строка заказа, пользователь или другая запись | Оставлено |
| `UPDATE` | Изменено | Изменились осмысленные поля существующей записи | Оставлено |
| `DELETE` | Удалено | Удалена бизнес-запись; её подпись и снимок сохраняются в журнале | Оставлено |
| `STATUS_CHANGE` | Смена статуса | Человек изменил статус договора, д.с. или заявки; также используется в цепочке активации д.с. | Оставлено отдельным действием для фильтрации |
| `FILE_UPLOAD` | Загружен файл | Загружен подписанный скан, исходник от организации или Excel для импорта | Оставлено |
| `FILE_DELETE` | Удалён файл | Пользователь выполнил мягкое удаление файла | Оставлено |
| `FILE_RESTORE` | Восстановлен файл | Ранее удалённый файл восстановлен | Оставлено |
| `COPY` | Копирование заказа (активация д.с.) | При активации дополнительного соглашения заказ копируется одной групповой записью | Переименовано из «Копирование заказа», чтобы указать причину события |
| `LOGIN` | Вход в систему | Успешный вход при включённой настройке аудита входов | Оставлено, но скрыто из журнала по умолчанию |

## Удалённые служебные варианты

| Тип/действие | Подпись | Когда возникало | Решение |
| --- | --- | --- | --- |
| `ACTIVATE` | — | Старый технический вариант активации | Удалён ранее; в фильтре отсутствует |
| `SEED_TEST_DATA` | — | Создание демонстрационных данных | Удалён ранее вместе с тестовым seed-функционалом |
| `DRAFT` | — | Старое внутреннее значение по умолчанию у `orders` и `document` | Удалено из текущих моделей и подписей; новые записи получают `CURRENT`. Единственная историческая запись аудита остаётся неизменяемой и отображается как «Действующий» |

## Правила отображения diff

- Идентификаторы и контекстные внешние ключи не показываются: объект уже
  указан в колонке «Объект», а автор и время — в отдельных колонках.
- Значимые ссылки, например факультет и специальность строки заказа,
  сохраняются в новой записи журнала готовой подписью, а не числовым ID.
- Подпись является снимком на момент события и не меняется при последующем
  переименовании или удалении связанной записи.
- Пароли, хеши, токены и содержимое файлов в diff не сохраняются.
- Если для нового поля нет явной русской подписи, журнал пишет предупреждение
  `entity_type + field_name`, а поле не показывает. Заглушки в интерфейсе нет.

## Отображаемые поля по событиям

В таблице перечислены поля, которые сотрудник может увидеть. Пустые значения и
поля без фактического изменения не выводятся.

| Объект и действие | Отображаемые поля |
| --- | --- |
| Организация — создано/изменено/удалено | УНП; краткое наименование; полное наименование; юридический адрес; ведомство; телефон |
| Договор — создано/изменено/удалено | Номер; дата начала; дата окончания; статус |
| Договор — смена статуса | Статус |
| Доп. соглашение — создано/изменено/удалено | Номер; дата; статус; предыдущее доп. соглашение; дата активации |
| Доп. соглашение — смена статуса | Статус |
| Заявка — создано/изменено/удалено | Номер; дата получения; дата подписания; статус |
| Заявка — смена статуса | Статус |
| Редакция заказа — создано/изменено/удалено | Статус; действующая редакция; предыдущая редакция заказа |
| Строка заказа — создано/изменено/удалено | Специальность; факультет; квалификация; профиль |
| Годовая потребность — создано/изменено/удалено | Год; потребность |
| Специальность — создано/изменено/удалено | Код; наименование; квалификация; факультет |
| Копирование заказа (активация д.с.) | Число скопированных строк; раскрываемый список специальностей, квалификаций и потребности по годам |
| Факультет — создано/изменено/удалено | Наименование; код |
| Привязка факультета к договору/заявке — создано/удалено | Факультет; сам документ указан в подписи объекта и поэтому повторно не выводится |
| Файл — загружен/удалён/восстановлен | Имя файла; назначение; формат; размер; дата удаления для операции удаления/восстановления |
| Импорт Excel — загружен файл | Имя файла; обработано строк; загружено организаций; создано договоров; добавлено строк заказа; связано факультетов |
| Пользователь — создано/изменено | Логин; ФИО; роль; активность; требование смены пароля; факт изменения пароля без значения |
| Пользователь — вход | Diff отсутствует; сотрудник и время указаны в колонках журнала |
| Настройки — создано/изменено | Параметр; значение; описание |

Не отображаются: числовые ID, внутреннее имя сохранённого файла, хеш и
значение пароля, содержимое файла, автор/время из технических колонок,
контекстные внешние ключи, номер внутренней редакции и версия карточки файла.
