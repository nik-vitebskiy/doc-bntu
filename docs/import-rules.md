# Правила импорта

- Действующая импортированная редакция заказа полностью редактируема: сотрудник может добавлять, изменять и удалять строки так же, как в ручной редакции.
- Повторный импорт того же документа считается источником истины и перезаписывает ручные изменения импортированного снимка. Это поведение осознанно подтверждено заказчиком.
- Отсутствующая в выгрузке опциональная колонка не очищает ранее сохранённое значение; пустая присутствующая ячейка обрабатывается как переданное пустое значение.
